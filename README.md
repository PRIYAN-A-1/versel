# 💪 FitnessDEP — Modern Fitness & Workout Platform

A modern, responsive fitness web application built with **Next.js, React, TypeScript, Tailwind CSS, Framer Motion, Recharts, Three.js, Zustand, React Hook Form, and Zod**.

FitnessDEP is designed as a polished digital fitness experience with interactive UI, workout-focused experiences, data visualization, client-side state management, and a deployment-ready Next.js architecture.

## ✨ Features

- 🏋️ Modern fitness-focused user interface
- 📱 Fully responsive design
- 🎨 Tailwind CSS based styling
- ✨ Smooth animations using Framer Motion
- 📊 Fitness data visualization with Recharts
- 🧊 Interactive 3D-ready experiences using Three.js
- ⚡ Next.js powered application architecture
- 🧠 Global state management with Zustand
- 📝 Form management with React Hook Form
- 🛡️ Schema validation with Zod
- 🔍 TypeScript and ESLint support
